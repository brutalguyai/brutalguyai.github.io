Brutal Test Kit: "Opus plans, Haiku does the work, at a fortieth of the price"

OVERHYPED

Tested 17 Nov 2026. Claude Code 2.1.326, headless (claude -p), API list prices. One small Python feature (monthly summary, duplicate finder, CLI report) with 12 hidden tests the agent never saw. 3 setups, 3 runs each. Not tested: big multi-day projects, auto-compaction, tuned prompt caching.

What happened

  • Haiku is 40x cheaper per token: true. Opus 5.5 $4 / $20 vs Haiku 5.5 $0.10 / $0.50 per 1M input / output tokens (Haiku price for prompts up to 100K tokens).
  • So the setup costs 1/40: not in my test. Opus was still 91% of the bill (90.6 to 92.1%): it plans, reads every subagent report and checks the work. Total tokens roughly tripled.
  • Haiku can do the work: yes, here. Haiku alone passed all 12 hidden tests every run.

Do it yourself

# the viral setup: CLAUDE.md + 4 subagents pinned to Haiku
cp setup/CLAUDE.md your-project/
mkdir -p your-project/.claude/agents && cp setup/agents/*.md your-project/.claude/agents/
cd your-project
claude -p "Implement the feature described in TASK.md. Test your work. When everything is done, reply DONE." \
  --model claude-opus-5-5 --output-format stream-json --verbose --max-turns 60 --permission-mode acceptEdits
# cost: the final "result" line has total_cost_usd and modelUsage per model
python3 -m pytest -q test_hidden.py   # run after, the agent never sees it

Full runner: run.sh · cost check: cost.py (recomputes cost from modelUsage; matches Claude Code's own number).

Fine print

  • One small feature. On long projects Opus's context grows and delegation might pay off; test it on your own work before you believe anyone, including me.
  • Subagent model: haiku only changes who writes the code. The main agent's planning and checking still runs on Opus.
  • Prices are API list prices. On a Claude subscription you pay in usage limits, not dollars, but the token mix works the same way.
