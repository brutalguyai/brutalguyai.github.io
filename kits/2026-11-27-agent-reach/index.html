Setup

Installed from the official release only: uv tool install --force https://github.com/Panniantong/Agent-Reach/releases/latest/download/agent-reach.zip. (The README warns the PyPI package named agent-reach is not this project, and there is no official token/coin.)

  • run_ar_phase1.ps1: install, version, setup, channels.
  • run_ar_phase2.ps1 + ar_harness.py: direct CLI tests (3× each) and 30 agent runs. "skill" = the agent-reach SKILL.md listed as an available skill + CLI on PATH; "plain" = no skill, agent-reach removed from PATH. Tools: run PowerShell, read file, write file; 25 turns / 120K tokens max per run.
  • cli_outputs.tgz: every CLI output + timings.csv. agent_logs.tgz: every step of all 30 agent runs. RESULTS.md: full write-up.

Caveats

  • The CLI test hit YouTube 9 times just before the agent runs, which may have triggered the 429.
  • Port 9222 was held by another browser debug session on this laptop.
  • The GitHub SSL error may be specific to this machine/network.
  • Login channels (X, Reddit browse, Instagram, Xiaohongshu…) were not tested: we don't log into accounts for tests. The README itself lists them as login-required.
