agent-browser: really 93% less context?

Repo: vercel-labs/agent-browser (v0.43.0, Apache-2.0) · about 50.8k stars, +4.4k this week on GitHub Trending.
Claim: the author's launch post (Chris Tate on X): "Up to 93% less context than Playwright MCP."

HALF-TRUE

The snapshots really are smaller than Playwright MCP's, but the 93% only showed up on example.com, a page with one link and no text. On real pages the compact snapshot (snapshot -i) was 44–82% smaller (median 69%), and it gets there partly by dropping non-interactive text. The full snapshot, the closest like-for-like comparison, was a median 32% smaller. The docs' "about 200–400 tokens" was not met on any of our 8 pages. Its safety checks mostly work, but a stale ref after navigating reported "Done" with exit code 0.

We measured output size, not whether an agent finishes tasks better. Tokens are estimated as characters ÷ 4; no model read the snapshots. 8 pages chosen by us, one day, one Playwright MCP version (0.0.85).

Run it yourself

npm install agent-browser @playwright/mcp@0.0.85
npx agent-browser open https://example.com
npx agent-browser snapshot -i        # compact: interactive elements only
npx agent-browser snapshot           # full accessibility tree
npx agent-browser click @e1
npx agent-browser close

We pointed both tools at the same Chrome build (AGENT_BROWSER_EXECUTABLE_PATH, --no-sandbox in our Linux container). Scripts start the small test page with python3 -m http.server 8801 inside fixture/.
