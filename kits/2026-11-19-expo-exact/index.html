The catches

  • Disk: setup ≈ 10.5 GB (checkout, its build folder, two pinned Rust toolchains, crates, caches); each app's own build folder 5-6 GB. Setup + one app ≈ 16 GB.
  • First native build: 13-14 minutes on this machine; rebuilds ~5 minutes. Much of each agent run was waiting for the compiler.
  • Edit speed: README says about 0.1 s (on an Apple Silicon Mac). Here: edit to page 1.95-2.53 s, per Exact's own dev log. Different hardware, but not 0.1 s on a small machine.
  • Pre-1.0: the README says it changes daily, with no API stability and no migration guide, by design.
  • Small friction: a new app doesn't list Linux; the agent had to add it to app.json after a build error.

Do it yourself

git clone https://github.com/expo/exact && cd exact
bun scripts/exact.mjs setup          # Bun 1.4.2 + Rust; first run takes a while
# then give Claude Code this prompt (README's own, adapted to web + Linux):
Follow its README to make a new Exact app with `exact new` at ../todo. Make a todo list where I can add items, check them off, delete them, and see how many are left. Put the view in Contract and keep the list in `app.ts`. Write an `app.test.contract`, pass it on web and Linux with `scripts/agent.mjs`, then save a screenshot of the running app on each.
