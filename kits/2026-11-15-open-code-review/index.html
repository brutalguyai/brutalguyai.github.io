Open Code Review: really 1/9 of Claude Code's tokens?

Repo: alibaba/open-code-review (CLI ocr v1.13.10, Apache-2.0) · about 50.8k stars, on GitHub Trending Nov 14.
Claim (README, Benchmark section): compared to Claude Code with the same model, higher precision and F1 "while consuming only ~1/9 of the tokens" and finishing faster. The README also says recall is lower, on purpose.

HALF-TRUE

In my test the token claim flipped. On a small 2-file PR both tools found all 6 planted bugs and used about the same tokens. On an 8-file PR, ocr used 3.4–4.3× more tokens than Claude Code (144–179K vs ~42K), took about 3× longer, and missed 1 of 8 bugs in all 3 runs. Where it clearly won: its line numbers were exact on all 39 findings; Claude Code's were exact on 12 of 42, usually 1–2 lines off.

Fine print: only 2 synthetic Python PRs with bugs I planted, one model (claude-sonnet-5-5), 3 runs each. Alibaba's benchmark uses 200 real PRs from 50 repos; on big PRs the result could be different.

Install + run (what worked)

npm install @alibaba-group/open-code-review@1.13.10
# point it at Anthropic with your own key
export OCR_LLM_URL=https://api.anthropic.com/v1/messages
export OCR_LLM_MODEL=claude-sonnet-5-5
export OCR_LLM_PROTOCOL=anthropic
export OCR_LLM_AUTH_HEADER=x-api-key
export OCR_LLM_TOKEN=$ANTHROPIC_API_KEY
npx ocr review --from main --to feature --format json --output result.json

The Claude Code side (same model, read-only tools):

claude -p "Review the changes on branch feature compared to main (git diff main...feature). Report each real bug or security issue with file and line. Be concise." \
  --model claude-sonnet-5-5 --max-turns 20 --output-format stream-json --verbose \
  --permission-mode acceptEdits --allowedTools "Bash(git:*)" Read Grep Glob

ocr prints a warning on git older than 2.41 (I had 2.34); it still ran.

Who it's for

Use it if you want a CI bot that leaves comments on the exact lines, or you review very large PRs (that's where Alibaba's numbers come from; I didn't test that).
Skip it if you just want a cheaper second look at everyday small PRs: in my test plain Claude Code was as good, cheaper and faster.
