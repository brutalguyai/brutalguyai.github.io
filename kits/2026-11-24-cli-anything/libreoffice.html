Two bugs, reproduced by hand outside the agent runs

  1. Formulas never compute. calc set-cell --formula writes of: + your text into the ODF file. LibreOffice shows: =SUM(A1:A2) → Err:510, =1+2 → Err:510, SUM(A1:A2) → Err:509, of:=SUM([.A1:.A2]) → saved as of:of:=... → Err:510, 1+2 → #NAME?. In the .xlsx export the cell holds the text =of:=SUM(A1:A2).
  2. Why: the tool never declares the of namespace in content.xml. Adding that one declaration to the same file makes both formulas compute (350 and 3), so the fix is small. The repo's own test only checks that the formula text is written, not that LibreOffice calculates it. Same result on two LibreOffice installs.
  3. Export without -p. export render flat_expenses.pdf (also .xlsx, .ods) writes an OpenDocument Text file with that name. With -p pdf|xlsx|ods it's correct.

Script: bug_repro.sh. Also: the SKILL.md says it works "without a GUI or LibreOffice installation" and then lists LibreOffice as a prerequisite; there is no chart command.
