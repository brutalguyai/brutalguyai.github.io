Fine print

  • OmniRoute's own README calls its "~1.62B tokens / month" an estimate of other providers' free tiers, not a grant, and says you bring your own accounts.
  • Your prompts and code go to whichever provider answers. Don't route private code.
  • Never give a router your paid Anthropic key unless you mean to.
  • One of the keyless providers failed only because the router wanted a browser runtime installed; with it, a fresh install might get further.
