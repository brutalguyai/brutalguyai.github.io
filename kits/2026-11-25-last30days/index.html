Brutal Test Kit: mvanhorn/last30days-skill with zero setup

HALF-TRUE v4.6.0 (commit 7c2e1c2b), Windows laptop, home connection in India. No keys, no logins. Tested 25 Nov 2026.

The claim

README: "Zero config. Reddit, HN, Polymarket, and GitHub work immediately." Its setup table lists those four as needing Nothing. TikTok, Instagram and X need a key per the README, so I did not count them against it.

How I ran it

  • run_test.ps1: the engine's own planner. "Claude Code" x3, "Kling AI", "Cursor", plus the built-in doctor --probe.
  • run_test2.ps1: the same engine with an agent query plan, the way Claude Code runs it (cursor, kling, claude-code). "Cursor" x2, "Kling AI" x2, "Claude Code". Reddit's 6-hour skip cache was cleared before every run, so Reddit got a fresh live try each time. It also does a plain request to Reddit from the same connection.
  • Raw outputs: round 1, round 2 (JSON results + each run's log).
