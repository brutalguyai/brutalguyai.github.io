Privacy Policy

Effective 26 October 2026

This policy covers Brutal Guy Publisher ("the app"), a private publishing tool operated by the owner of the Brutal Guy AI channel.

Who uses the app

The app is used only by the channel owner to publish the channel's own content. It is not offered to the public.

Data the app accesses

  • YouTube (via YouTube API Services): permission to upload videos to the owner's own YouTube channel (scope youtube.upload).
  • Instagram (via the Instagram API): basic profile information of the owner's own account, permission to publish media and to manage comments on its own posts.

How data is used

Access is used solely to upload and publish videos, images and captions created for the channel, and to reply to comments on its posts. No data is sold, shared with third parties, used for advertising or used to train AI models.

Storage

Access tokens are stored only on the owner's own computer in a private configuration file. The app does not run a server database and does not store any viewer's personal data.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at Google security settings.

Instagram

Use of Instagram is subject to Meta's Privacy Policy. Access can be removed in Instagram under Settings, Website permissions, Apps and websites.

Deletion

To delete stored tokens, revoke access using the links above; the owner then deletes the local configuration file. Requests: theamazingbeings@gmail.com.

Changes

Updates to this policy will be posted on this page with a new effective date.
